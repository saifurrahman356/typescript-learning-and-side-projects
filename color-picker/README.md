# Color Picker

Practice TypeScript union types, type guards, and DOM events.

## Prerequisites

- Node.js (LTS recommended)
- npm

## Install dependencies

```bash
npm install
```

## Build TypeScript

```bash
npm run build
```

## Check TypeScript types

```bash
npm run typecheck
```

## Run in the browser

Start a local static server from this project directory:

```bash
npm run serve
```

Then open the URL shown in the terminal (usually `http://localhost:8080`) and select `index.html` if the server shows a directory listing.

The `dist/` directory is generated by the build command and should not be committed.
